# Restaurant OS 10.3.2

Correct period semantics.

- Сегодня: факт на текущий момент + прогноз дня.
- Вчера: завершённый факт; без формулировок «при текущем темпе».
- 7 дней: факт выбранного периода и сравнение с предыдущими 7 днями.
- Этот месяц: факт с начала месяца + прогноз до конца месяца.
- Прошлый месяц: окончательный факт.
- План и «Что сделать сейчас» используют факт для завершённых периодов и прогноз только там, где период ещё продолжается.
