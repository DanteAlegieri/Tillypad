# Restaurant OS 8.2.0

## Рабочий стол директора

- исправлена вёрстка карточек «Требует внимания»;
- добавлен расчёт индекса ресторана при отсутствии серверной оценки;
- расширено распознавание структуры данных ТОП-5;
- улучшены графики и пустые состояния;
- блок оплат показывает честный статус «Источник не подключён».

Данные оплат в этот релиз не выдумываются: для них потребуется отдельный SQL-запрос Tillypad и расширение протокола Agent/Gateway.
