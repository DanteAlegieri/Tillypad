# Restaurant OS 9.0.0 — Digital Director

Добавлены:

- объяснимый индекс ресторана;
- директорский вывод о причине изменения показателей;
- прогноз выручки по текущему темпу;
- центр решений с приоритетами;
- модальное окно с факторами оценки.

Оплаты, возвраты, скидки и активные заказы не имитируются. Для них потребуется отдельное расширение SQL и протокола Agent/Gateway.
