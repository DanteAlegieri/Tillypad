# Restaurant OS 10.3.4

## Comparable periods and live restaurant state

- Сегодня сравнивается со вчера.
- Вчера — с позавчера.
- 7 дней — с предыдущими 7 днями.
- Этот месяц (MTD) — с тем же числом дней прошлого месяца.
- Прошлый месяц — с позапрошлым месяцем.
- Блок «Ресторан сейчас» использует последний live snapshot и не зависит от фильтра периода.
- Пиковый час рассчитывается из последнего почасового snapshot.
- Агент передаёт реальную последнюю проданную позицию за текущий день; Gateway больше не подменяет её лидером периода.
