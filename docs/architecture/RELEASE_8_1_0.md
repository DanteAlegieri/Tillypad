# Restaurant OS 8.1.0

## Периоды

- Сегодня.
- Вчера.
- Последние 7 дней.
- Текущий месяц.
- Полный прошлый месяц.

Период сохраняется в URL: `/dashboard?period=prevmonth`.

## История

Windows Agent 31.1.0 при подключении один раз отправляет последние 70 дней продаж. Это необходимо, потому что Gateway не может получить июльские данные, если облачные снимки начали накапливаться только в августе.
