# Security Policy

## Никогда не публиковать

- `.env`
- административные токены Gateway
- API-ключи агентов
- SSH private keys
- реальные SQL-пароли
- базы данных с коммерческими данными

## Сообщение об уязвимости

Не создавайте публичный Issue с секретами или эксплуатационными данными.
Сначала отзовите скомпрометированный ключ и создайте новый.
