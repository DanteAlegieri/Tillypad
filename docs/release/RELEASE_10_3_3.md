# Restaurant OS 10.3.3

Period data isolation.

Исправлено:

- старые асинхронные ответы больше не перерисовывают новый выбранный период;
- каждый запрос фиксирует свой `requestedPeriod`;
- график получает период явно, а не читает изменившуюся глобальную переменную;
- расчёт плана текущего и прошлого месяца использует полный календарный месяц;
- при переключении периода заголовок показывает состояние обновления до прихода актуального ответа.

Причина ошибки 10.3.2: запрос «Вчера» мог завершиться после выбора «Этот месяц» и перерисовать данные вчерашнего дня под уже новыми месячными подписями.
