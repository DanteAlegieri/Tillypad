# ADR-001: Сохраняем monorepo

## Решение

Пока Agent, Gateway, AI и документация остаются в одном репозитории.

## Причины

- продукт ещё быстро меняется;
- общие версии проще синхронизировать;
- один Pull Request может обновлять протокол и обе стороны;
- отдельные репозитории пока усложнят выпуск релизов.

## Будущее

Разделение возможно после стабилизации протокола Agent ↔ Gateway.
