# ADR-002: Название продукта Restaurant OS

## Решение

Название продукта — Restaurant OS.

TillyPad рассматривается как первый POS-адаптер, а не название всей платформы.

## Репозиторий

Текущий репозиторий можно временно оставить `Tillypad`.
Позже его можно переименовать в `restaurant-os` через настройки GitHub.
GitHub сохраняет перенаправления со старого URL.
