# Restaurant OS 10.3.5

Agent selection stability.

- Пустые `agent_id` больше не попадают в селектор.
- `gastrodom3` выбирается приоритетно, если присутствует.
- Выбранный ресторан сохраняется в `localStorage`.
- При пустом/повреждённом списке агентов используется безопасный fallback `gastrodom3`.
- `loadDashboard()` не отправляет запросы с пустым `agent_id`.
- Если агент передал `latest_sale`, но сегодня продаж нет, live-блок показывает «Сегодня продаж ещё не было».
