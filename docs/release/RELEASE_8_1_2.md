# Restaurant OS 8.1.2

## Цель

Сделать один согласованный источник кода и прекратить расхождение между:

- локальной папкой;
- ветками GitHub;
- кодом на VPS.

## Версии

- Gateway: 8.1.2
- Agent: 31.1.0

## Основная схема веток

- `main` — только проверенные релизы;
- `develop` — актуальная рабочая версия;
- `release/8.1.2` — текущая релизная ветка;
- `feature/*` — новые функции.

## Порядок

1. Распаковать архив поверх `C:\TillypadDashboard`.
2. Проверить локальный запуск и содержимое файлов.
3. Запустить `scripts\align_git_release.ps1`.
4. Проверить ветку `develop`.
5. Выполнить деплой Gateway с ожидаемой версией `8.1.2`.
6. После успешного теста выполнить скрипт с `-UpdateMain`.

## Запрещено

- деплоить код из старой feature-ветки;
- вручную менять версию только в одном файле;
- использовать ZIP и Git одновременно без коммита;
- делать force push в `main`.
