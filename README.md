# TillyPad Restaurant OS

Первая стабильная архитектурная версия проекта для «Гастродома №3».

## Возможности

- прямое подключение к SQL Server Tillypad через Radmin VPN;
- SQL-дашборд по таблице `dbo.tp_Guests`;
- SQL Explorer:
  - поиск таблиц;
  - количество строк;
  - поиск колонок;
  - структура таблицы;
  - безопасный `SELECT TOP`;
- логирование;
- настройки через `.env`;
- разделение кода на:
  - подключение к БД;
  - репозитории;
  - сервисы;
  - веб-маршруты;
  - шаблоны.

Все SQL-запросы используют только `SELECT`.

## Установка

1. Сохраните старый файл `.env`.
2. Распакуйте архив в:

```text
C:\TillypadDashboard
```

3. Скопируйте `.env.example` в `.env`.
4. Заполните:

```env
TILLYPAD_SQL_SERVER=26.187.75.193
TILLYPAD_SQL_PORT=1433
TILLYPAD_SQL_DATABASE=TillypadSegment
TILLYPAD_SQL_USER=ваш_sql_логин
TILLYPAD_SQL_PASSWORD=ваш_sql_пароль
TILLYPAD_SQL_DRIVER=ODBC Driver 18 for SQL Server
TILLYPAD_SQL_ENCRYPT=no
TILLYPAD_SQL_TRUST_CERTIFICATE=yes
TILLYPAD_SQL_TIMEOUT=10
```

5. Запустите `install.bat`.
6. Запустите `run.bat`.

## Продажи

Новая страница:

```text
http://127.0.0.1:8000/sales
```

Показывает:

- выручку за выбранный период;
- количество чеков;
- средний чек;
- количество проданных единиц;
- продажи по часам;
- топ блюд;
- последние чеки.

Текущая формула:

```text
orit_Count × orit_Price
```

Пока отчёт не исключает отменённые позиции, возвраты и служебные движения.
Следующий этап — определить назначение `orit_mvtp_ID` и статусов заказа.

`analysis["items"]`.


## v2.0.2

недоступна в отдельном блоке `scripts`. В JavaScript-шаблоне используются
прямые обращения к `result.analysis`.

## v15.0 — TillyPad Relay Agent

Добавлен промежуточный сервис для нестабильного VPN.

Схема:

1. Relay Agent запускается на компьютере в локальной сети TillyPad.
2. Он подключается к SQL Server напрямую внутри сети.
3. Restaurant OS обращается к агенту по HTTP/HTTPS.
4. Разрешены только SELECT и CTE-запросы.
5. При кратком обрыве выполняются повторные попытки.
6. Если агент не отвечает, используется последний кэш точно такого же запроса.

### Запуск агента

1. На компьютере рядом с TillyPad скопировать проект.
2. Создать `.env` по примеру `.env.relay.example`.
3. Запустить `run_relay_agent.bat`.
4. Опубликовать порт 8010 через защищённый HTTPS-туннель или reverse proxy.

### Настройка Dashboard

В `.env`:

```env
TILLYPAD_CONNECTION_MODE=relay
TILLYPAD_RELAY_URL=https://ваш-защищенный-адрес
TILLYPAD_RELAY_API_KEY=тот-же-длинный-секретный-ключ
TILLYPAD_RELAY_TIMEOUT=15
TILLYPAD_RELAY_RETRIES=2
TILLYPAD_RELAY_ALLOW_STALE_CACHE=true
```

SQL Server нельзя публиковать напрямую в интернет. Наружу выводится только Relay Agent, защищённый API-ключом и HTTPS.
