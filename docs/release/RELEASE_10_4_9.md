# Restaurant OS 10.4.9 — Purchases from TillyPad

Agent 31.5.0.

## Источник закупок
- `tp_InputDocuments`
- `tp_InputDocumentItems`
- `tp_Partners`

Учитываются только документы:
- `idoc_idst_ID = 1`
- строки с `idit_IsDeleted = 0`

Сумма закупки:
- `SUM(idit_Sum)`

НДС показывается отдельно:
- `SUM(idit_SumVAT)`

## Finance
- закупки автоматически входят в общий показатель «Расходы»;
- ручные расходы остаются отдельно;
- отдельный блок показывает документы, сумму, НДС и крупнейших поставщиков;
- закупки не называются Food Cost / себестоимостью реализации.
