# Agent 31.6.2 — Auto Discover Food Cost Tables

- автоматически ранжирует складские, продажные, продуктовые и стоимостные таблицы;
- сохраняет до 40 наиболее вероятных кандидатов;
- для каждой таблицы сохраняет структуру, количество строк и до 15 реальных записей;
- сохраняет внешние ключи между найденными кандидатами;
- диагностика строго read-only.
